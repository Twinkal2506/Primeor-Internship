
# Primeor Solutions — Web Development Internship

A collection of six web development projects completed as part of the Primeor Solutions Web Development Internship Program.

## Projects

### Level 1 — Fundamentals

**Task 1: NOVA Digital Studio**
- HTML and CSS webpage
- Navigation, hero section and contact form
- Responsive styling

**Task 2: JavaScript Playground**
- Interactive background color changer
- Time-based greeting
- Addition calculator with input validation

### Level 2 — Frameworks & Responsive Design

**Task 1: The Daily Brew**
- Responsive coffee shop website
- Bootstrap components and grid system
- Interactive menu cards and animations

**Task 2: The Workshop Edit**
- Responsive creative workshop website
- Mobile navigation
- Workshop category interactions
- Responsive layouts using CSS media queries

### Level 3 — Advanced Projects

**Task 1: AFTERIMAGE**
- Editorial-style visual gallery
- Interactive image lightbox
- Slideshow with play and pause controls
- Responsive image presentation

**Task 2: Primeor Internship Landing Page**
- Internship program landing page
- Company introduction and program information
- Benefits and qualifications sections
- Responsive navigation and layout
- Company contact information

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Bootstrap 5
- Responsive Web Design
- Git and GitHub

## How to Run

1. Clone or download this repository.
2. Open the desired project folder.
3. Open its `index.html` file in a web browser.
4. Explore the project and its interactive features.

Some projects use externally hosted fonts, images or frameworks and may require an internet connection.
